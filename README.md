# 江苏烟草企业综合管理平台（演示）

可交互 Web Demo，完整覆盖战略规划、目标绩效、经济运行、科技创新、对追达创五大模块，以及经济运行分析智能体的“指标监测 → 异常预警 → 智能研判 → 证据核验 → 人工确认 → 通报/督办”闭环。

所有页面、分析结果和导出草稿均为**演示环境 / 合成演示数据**，不包含真实经营数据。

## 启动

```bash
npm install
npm run dev
```

- 前端：`http://localhost:5173/login`
- 后端健康检查：`http://localhost:3001/api/demo/health`

常用命令：

```bash
npm run build
npm run test
npm run lint
npm run demo:health
npm run demo:reset
```

## Kimi K3 实时模型

智能体仅调用 Kimi K3 实时模型，不提供缓存结果、缓存模式或自动降级。未提供模型环境变量、模型不可用或返回不满足受控格式时，本次分析会明确失败，用户需检查服务端配置或网络后重试。

Kimi K3 采用 OpenAI 兼容接口，仅在服务端读取环境变量；切勿将密钥写入源代码、前端变量或提交到仓库。

```bash
export MODEL_BASE_URL=https://api.moonshot.cn/v1
export MODEL_NAME=kimi-k3
export MODEL_API_KEY='your-server-side-secret'
npm run dev
```

Kimi K3 仅基于服务端受控工具返回的指标、证据和业务上下文生成分析文字；指标数值、风险、证据、建议和通报框架仍由受控数据与规则校验，避免模型新增未经证据支持的事实。

`/demo-control` 仅展示 Kimi K3 的实时配置状态和一键重置，不显示密钥或内部提示词。

## 现场主演示路径

1. 登录后进入 `/portal`，快速展示五大模块。
2. 依次进入战略规划、目标绩效、科技创新、对追达创，分别完成详情与业务动作。
3. 进入 `/economy`，打开“库存状态指数”预警，查看口径和组织下钻。
4. 点击“智能研判”，在 `/economy/agent` 启动预置问题。
5. 展示受控执行步骤、结构化结果与证据抽屉。
6. 编辑并完成人工确认，再保存通报草稿、生成督办任务草稿。
7. 答辩备用入口：`/simulation/tax-profit`；演示保障和一键重置：`/demo-control`。

### 可切换的现场业务场景

在 `/economy/agent` 左侧“现场业务场景库”可一键切换并运行：

- **月度总体运行分析**：销售、税利、结构、库存、价格的完整主演示闭环。
- **税利进度差异研判**：以税利完成进度 94.6% 及其目标差异为数据线索，生成核验建议和跟踪任务。
- **销售结构与价格联动分析**：以结构指数 101.7、价格指数 99.4 为数据线索，区分事实与待核验原因，形成结构优化建议。

每个场景均包含独立的预警、结构化结果、证据、分析假设与建议，并可走完“人工确认 → 通报/任务草稿”过程。

### 修改数据后现场分析

在智能体左侧“本次分析数据（可修改）”区域：

1. 勾选需要纳入本次分析的指标。
2. 修改每项的当前值和目标值（后两列）。
3. 点击“启动预置分析”。

服务端将把这份本次提交的合成数据快照写入任务上下文，重算关键指标、差异、风险、事实、建议、通报框架和证据摘要。结果页面的证据 E1 会明确标注为“业务人员修改并确认的合成演示数据”，避免与固定场景数据混淆。

确认分析结果后，点击“生成督办任务”会自动带入本次分析的首要风险、责任部门、完成时限和处置要求，打开可编辑的督办任务草稿；保存后任务状态进入“已保存”，可在门户待办中体现。

## 已知限制

- 这是现场 Demo，不连接真实数据库、审批或身份认证系统。
- 当前 Kimi 调用以文字润色为受控增强；正式生产需在服务端配置权限、审计、模型网关和真实知识库。
- Playwright 测试需要首次安装浏览器：`npx playwright install chromium`。
